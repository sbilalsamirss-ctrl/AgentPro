Hardware & System Requirements

AgentPro is engineered to run seamlessly even on budget workstation hardware without compromising call audio quality.

Component Minimum Requirement Recommended Specification
Operating System Windows 10 (64-bit) / macOS 12 Monterey Windows 11 (64-bit) / macOS 14 Sonoma
Processor (CPU) Dual-Core 2.0 GHz Intel / AMD / Apple M1 Quad-Core 2.5 GHz+ / Apple Silicon (M1/M2/M3/M4)
Memory (RAM) 4 GB System RAM 8 GB System RAM or higher
Disk Storage 500 MB free disk space for application SSD storage for high-volume audio caching
Audio / Headset Standard 3.5mm or USB Audio Headset Noise-cancelling USB / Bluetooth VoIP Headset
Network 1 Mbps broadband with < 100ms ping to PBX Ethernet connection with < 20ms jitter to SIP Server
