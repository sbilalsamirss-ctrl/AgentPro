  • ✔️ تصدير فوري للتقارير بصيغ PDF و Excel

  • ✔️ أتمتة كاملة لإنشاء وتعيين التذاكر
  • ✔️ تنبيهات ذكية قبل تجاوز حدود الـ SLA

  • ✔️ فصل ستريو متكامل لصوت المتحدثين

يعمل AgentPro بكفاءة عالية على الأجهزة المتوسطة دون استهلاك موارد الذاكرة أو المعالج.

⚙️ الأداء ومواصفات الأجهزة

استهلاك الذاكرة: < 120 MB RAM فقط

استهلاك المعالج: أقل من 1.5% أثناء التسجيل

أنظمة التشغيل: Windows 10/11 (64-bit) و macOS 12+

محرك الصوت: DirectSound / WASAPI / CoreAudio

🔒 الأمان وقواعد البيانات المدعومة

التشفير: AES-256 و TLS 1.3 لنقل البيانات

قواعد البيانات: PostgreSQL, MySQL, SQLite, MSSQL

أنظمة الـ PBX: Asterisk, FreePBX, 3CX, Cisco, SIP

العمل دون اتصال: تخزين محلي مؤقت ومزامنة تلقائية

إجابات عن استفساراتك

يتوافق AgentPro بشكل كامل مع Asterisk, FreePBX, 3CX, Cisco Unified Communications, Twilio Voice، وكافة بروتوكولات الـ SIP / WebRTC القياسية.
نعم 100%، يدعم البرنامج قواعد البيانات المحلية والذاتية (On-Premises) مثل PostgreSQL و MySQL و SQLite و MSSQL، وتبقى كافة تسجيلاتك وبيانات عملائك داخل شبكتك الخاصة.
يمكنك زيارة صفحة أكاديمية الكورسات للاطلاع على كافة الدروس والفيديوهات المضافة دورياً مع تحميل ملفات التطبيق وقوالب العمل المرفقة مع كل درس.
