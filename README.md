# 🎧 منصة AgentPro - بوابة النظام وأكاديمية الكورسات والبرامج

أهلاً بك في المستودع الرسمي لموقع **AgentPro**، المنظومة المتطورة لإدارة الكول سنتر وأكاديمية الشروحات والكورسات العملية.

الموقع مبني بهيكلية برمجية مستقلة (Standalone Vector SVGs & CSS) تضمن عمل الموقع بنسبة 100% على **GitHub Pages** دون أي مشاكل في الصور أو الروابط المفقودة.

## 👑 تسجيل دخول المشرف (Admin Access)

- **البريد الإلكتروني:** `admin@samt.com`
- **كلمة المرور الافتراضية:** `admin1234`
- **كود إنشاء حساب أدمن جديد:** `SAMT-ADMIN-2026`

> عند تسجيل الدخول بهذا الحساب من زر **"تسجيل الدخول"** الطبيعي في الموقع، يتفعل **وضع المشرف (Admin Mode)** تلقائياً، وتظهر أزرار التعديل والحذف المباشرة فوق كل كورس في صفحة الكورسات.

---

## 🎓 كيف تضيف أو تعدل كورس من الموقع مباشرة؟

1. اضغط على **"تسجيل الدخول"** وسجل بحساب الأدمن (`admin@samt.com`).
2. اذهب إلى صفحة الكورسات `courses.html`.
3. اضغط على زر **[➕ إضافة كورس جديد]** في الشريط العلوي، أو زر **[✏️ تعديل]** فوق أي كورس.
4. املأ البيانات واضغط **[حفظ الكورس]**.
5. لتصدير التحديثات لـ GitHub، اضغط على زر **[تصدير البيانات]** من القائمة المنسدلة لحسابك.

---

## 🚀 كيفية رفع التحديثات إلى GitHub Pages

1. افتح صفحة المستودع: **[https://github.com/sbilalsamirss-ctrl/AgentPro](https://github.com/sbilalsamirss-ctrl/AgentPro)**
2. اضغط على **Add file** ⬅️ **Upload files**.
3. اسحب الملفات التالية وضعها في المتصفح:
   - `index.html`
   - `courses.html`
   - `downloads.html`
   - `course-view.html`
   - `admin.html`
   - `assets/js/courses-data.js`
   - `assets/js/auth.js`
4. في الأسفل، اضغط على الزر الأخضر **Commit changes**.
5. سيعمل الموقع فوراً بكافة التحديثات!
